## 🚀 Key Modules

<details open>
<summary><strong>📊 1. Dashboard Metrics Overview</strong></summary>
<br>
Real-time status indicators tracking total patients, active on-duty doctors, daily scheduled appointments, and available hospital ward beds.
</details>

<details open>
<summary><strong>👥 2. Patient Directory & Management</strong></summary>
<br>
Register new patients, view detailed medical records, search dynamically across name or contact info, and execute patient deletions with cascading bed releases.
</details>

<details open>
<summary><strong>🩺 3. Doctor & Staff Registry</strong></summary>
<br>
Department-wise categorization (Cardiology, Neurology, Orthopedics, General Surgery) with real-time duty status monitoring.
</details>

<details open>
<summary><strong>📅 4. Appointment Scheduling</strong></summary>
<br>
Interactive appointment booking system linking registered patients with specialized doctors, complete with instant status toggles.
</details>

<details open>
<summary><strong>🛏️ 5. Inpatient Room Allocation Matrix</strong></summary>
<br>
Visual bed management grid allowing admins to assign outpatients to ICU, Private, Semi-Private, or General ward beds and execute discharges in real-time.
</details>

## ⚡ Quick Setup & Running Locally

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/rishavmandal/Hospital_Management.git
   cd Hospital_Management
   ```

2. **Run the Application:**
   * Double-click `index.html` to launch directly in any modern web browser.
   * *No build step or Node environment required!*
